# Reusable Packages

- `sdk`: JSON-RPC process runtime and loopback UI server.
- `ui-bridge`: iframe props, theme, submit, and cancel messaging.
- `ui-tokens`: CSS custom properties, utilities, and runtime token helpers.

Each directory is independently published under the `@flyto2` npm scope. The
[generated source API](../docs/generated/source-api.md) records every named
production declaration.
