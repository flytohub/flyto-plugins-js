# Generated References

These files are derived from maintained source contracts:

- `source-api.md`: every named production class, type, function, constructor,
  and method in package, plugin, and embedded UI source.
- `plugin-contracts.md`: every step, input, output, UI setting, and secret from
  the three `plugin.yaml` manifests.
- `ui-tokens.md`: every published Flyto2 CSS custom property and utility class.

Run `npm run docs:generate` after source changes. `npm run docs` and CI reject
stale output.
